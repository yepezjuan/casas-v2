# Introduction

Do you have a relative or friend who visits multiple locations a day for work and need to keep track of client contact info?
CASAS is here to help, we keep things simple. You have places to go and we show you the best way of getting there. CASAS will also keep track of that clients visit history for 30 days so you know, when it may be the next time they need a visit

# Objective

CASAS is aiming to reduce headache of figuring out where you need to go work for the day. As well staying alert of any traffic for your client routes

# Who is this for?

Anyone who is a salesman and has to physically go to different clients on a daily basis and not have to punch in the next client every time they get back in the car

# Behind the scenes of building this

This app is planned to be out a hosted app for everyone to use. Mainly in California for early stages.

# Install

`npm install`

# Things to add

- Create a `.env` file in config folder and add the following as `key = value`
  - PORT = 2121 (can be any port example: 3000)
  - DB_STRING = `your database URI`

# Run
